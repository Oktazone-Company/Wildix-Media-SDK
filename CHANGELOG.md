# Changelog

All notable project changes are documented here. The format follows Keep a Changelog,
and versioning follows Semantic Versioning while the public API is in alpha.

## [Unreleased]

### Added

- Professional project documentation and repository metadata
- Continuous integration for linting, type checking, tests, and package builds

## [0.1.0] - 2026-09-03

### Added

- Incoming SIP over TCP and UDP
- PCMA and PCMU SDP negotiation
- Bidirectional asynchronous RTP/PCM call API
- Tunnel-aware advertised SIP and RTP configuration
- RTP port allocation and bounded media queues
- RFC 2833 DTMF input and output
- WAV recording utility and record-and-echo example
- Unit and loopback SIP/RTP integration tests
